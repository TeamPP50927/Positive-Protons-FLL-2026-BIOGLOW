# Programming Standards

## Team rules

- Use clear names for variables and functions.
- Keep reusable robot code in `robot/`.
- Keep mission-specific logic in `runs/`.
- Comment the starting position and important alignment points.
- Test physical behavior before requesting a merge.
- Do not directly edit the competition branch during tournament day without a backup tag.

## Commit messages

Use short, descriptive messages, for example:

- `Improve Run 03 alignment`
- `Add gyro turn helper`
- `Fix attachment motor direction`
