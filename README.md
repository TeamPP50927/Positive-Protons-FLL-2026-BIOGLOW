# Positive Protons - FLL 2026-2027 BIOGLOW

Team programming repository for the Positive Protons FLL robot using Pybricks.

## Team workflow

1. Create an issue for the work.
2. Create a branch for the change.
3. Code and test on the robot.
4. Commit with a clear message.
5. Open a pull request.
6. Have another student test/review the change.
7. Merge only after robot testing passes.

## Competition protection

`main` is the team stable branch. Competition versions should be tagged, for example `competition-01`.

## Repository layout

- `main.py` - hub menu / entry point
- `robot/` - shared robot functions
- `runs/` - mission run programs
- `experiments/` - tests and prototypes
- `documentation/` - team programming and robot standards
- `season/` - goals, testing history, and meeting notes
